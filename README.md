### 🚀 Quick Start

#### Prerequisites
- Node.js 20+ and npm


#### Installation

1. **Clone the repository**
```bash
git clone https://github.com/galafis/Criando-uma-Homepage-com-React.git
cd Criando-uma-Homepage-com-React
```

2. **Install dependencies**
```bash
npm install
```

#### Running

```bash
npm run dev
```
